## Tech Stack

- JavaScript

## Coding Rules

- Write clean and readable code.
- Use reusable components.
- Follow Conventional Commits.
- Explain changes before implementing them.

## Additional Guidelines

- Use meaningful variable names.
- Write reusable React components.
- Keep commit messages in Conventional Commits format.

## Project Rules Learned (Week 2)

1. Use controlled React components for all form inputs instead of uncontrolled inputs.

2. Validate required fields and email format before allowing form submission.

3. Associate every form field with a visible label and appropriate ARIA attributes (`aria-invalid` and `aria-describedby`) for accessibility.

4. Review AI-generated code against the project requirements before accepting it.

5. Run the application after every major AI-generated change to verify there are no runtime errors.
